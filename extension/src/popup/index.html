Context Memory
Have the model write a one-sentence summary each page and reuse it on later pages of the same story, so characters/events stay consistent. Cheaper than Previous-page context — no images or full OCR text sent.
Translate pages one at a time
With Auto-translate/batch running several pages in parallel, a page can start before an earlier page has written its Context Memory summary, so it never sees it. Keep this on to translate strictly in order — slower, but later pages reliably see what earlier pages established (e.g. who's family/siblings). Turn off to keep parallel speed and accept that some pages may miss recent context.
